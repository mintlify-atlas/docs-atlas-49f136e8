MC Modeler is a web-based BPMN 2.0 process modeling tool that runs entirely in your browser — no installation required. Inspired by Bizagi Modeler, it brings professional process documentation to any operating system, with real-time collaboration, cloud persistence, and full interoperability with the OMG BPMN 2.0 standard.

## Architecture at a Glance

MC Modeler is a **React 19 + TypeScript SPA** built on [bpmn-js v18](https://bpmn.io/toolkit/bpmn-js/) — the same BPMN engine used by Camunda Modeler. The persistence layer is abstracted behind the `IDiagramRepository` interface, so the app works offline with `localStorage`/IndexedDB and upgrades to full cloud collaboration when connected to Supabase.
