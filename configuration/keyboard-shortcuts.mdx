Keyboard shortcuts let you perform the most common modeling actions without leaving the canvas. All shortcuts are global — they work whenever focus is on the canvas (not in a text input, textarea, or dropdown).

<Tip>
  Open the **Keyboard Shortcuts** modal at any time by pressing <kbd>?</kbd>, or from the menu bar via **View → Keyboard Shortcuts**. The modal reflects the correct modifier key for your platform automatically.
</Tip>

## Platform Notes

MC Modeler detects your platform at runtime and displays the appropriate modifier key in the shortcuts modal. The tables below use both notations:

| Platform | Modifier key shown |
|----------|--------------------|
| macOS | <kbd>⌘</kbd> (Command) |
| Windows / Linux | <kbd>Ctrl</kbd> |

Where you see **Mod** in the source, substitute <kbd>⌘</kbd> on Mac or <kbd>Ctrl</kbd> on Windows/Linux.

## Canvas Navigation

| Shortcut (Win/Linux) | Shortcut (Mac) | Action |
|----------------------|----------------|--------|
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | <kbd>⌘</kbd>+<kbd>+</kbd> | Zoom in |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd>+<kbd>-</kbd> | Zoom out |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Fit diagram to screen |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | <kbd>⌘</kbd>+<kbd>0</kbd> | Reset zoom to 100% |

## Editing

| Shortcut (Win/Linux) | Shortcut (Mac) | Action |
|----------------------|----------------|--------|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | <kbd>⌘</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | <kbd>⌘</kbd>+<kbd>C</kbd> | Copy selected elements |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | <kbd>⌘</kbd>+<kbd>X</kbd> | Cut selected elements |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | <kbd>⌘</kbd>+<kbd>V</kbd> | Paste elements |
| <kbd>Del</kbd> | <kbd>Del</kbd> | Delete selected elements |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | <kbd>⌘</kbd>+<kbd>A</kbd> | Select all elements |

<Note>
  Redo can also be triggered with <kbd>Ctrl</kbd>+<kbd>Y</kbd> (Windows/Linux) as an alternative to <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>. Both are handled by the keyboard hook.
</Note>

## File Operations

| Shortcut (Win/Linux) | Shortcut (Mac) | Action |
|----------------------|----------------|--------|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | <kbd>⌘</kbd>+<kbd>S</kbd> | Save diagram |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | <kbd>⌘</kbd>+<kbd>N</kbd> | Open New diagram dialog |

Import (<kbd>File → Import BPMN…</kbd>) and Export (<kbd>File → Export…</kbd>) are available from the menu bar and do not have dedicated keyboard shortcuts — use the menu or toolbar buttons for those actions.

---

## View & Validation

| Shortcut (Win/Linux) | Shortcut (Mac) | Action |
|----------------------|----------------|--------|
| <kbd>F5</kbd> | <kbd>F5</kbd> | Validate diagram (opens Validation panel) |

The Properties panel and Comments visibility can be toggled via **View → Properties panel** and **View → Comments** in the menu bar.

---

## Shortcuts Modal

| Shortcut (Win/Linux) | Shortcut (Mac) | Action |
|----------------------|----------------|--------|
| <kbd>?</kbd> | <kbd>?</kbd> | Open Keyboard Shortcuts modal |

Pressing <kbd>?</kbd> anywhere on the canvas opens the built-in shortcuts reference modal. The modal groups shortcuts by category (Canvas, Edit, View, Diagram) and renders the correct modifier key for your OS automatically.
